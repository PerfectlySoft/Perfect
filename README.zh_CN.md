# Perfect：服务器端 Swift

Perfect 是一组专注的 Swift 包，用于构建服务器以及访问其背后的服务：HTTP(S) 服务器、数据库驱动、会话与登录、邮件、推送通知、FileMaker、支付和常用工具。所有包都基于 Swift 6 和严格并发编写，支持 macOS 与 Linux，依赖尽量精简，各自独立发布和测试。

**本仓库原先是 PerfectLib**，即最初的一体化 Perfect 框架（Swift 3 至 5），现已不再维护。其代码保留在 [`legacy`](https://github.com/PerfectlySoft/Perfect/tree/legacy) 分支，原有版本标签（最新为 4.0.1）仍可解析。

新项目请从 [PerfectTemplate](https://github.com/PerfectlySoft/PerfectTemplate) 和 [Perfect-NIO](https://github.com/PerfectlySoft/Perfect-NIO) 开始。完整的包列表、各包说明以及从 PerfectLib 迁移的对照表，请参阅[英文 README](README.md)。
